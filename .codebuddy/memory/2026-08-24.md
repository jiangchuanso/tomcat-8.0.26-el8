# 2026-08-24

## tomcat8 RPM 构建 (GitHub Actions)
- 项目把 Tomcat 8.0.26 打成 RPM。原 `tomcat8.spec` 是纯 noarch（只拷贝发行包到 /opt/tomcat8）。
- 改造 `tomcat8.spec`：主包 `tomcat8` 保持 noarch；新增 arch 子包 `tomcat8-native`，在 `%build` 中编译
  `bin/commons-daemon-native.tar.gz`（jsvc）与 `bin/tomcat-native.tar.gz`（libtcnative-1）。
  - libtcnative-1.so* 装入 `%{_libdir}`(/usr/lib64，JRE 默认 java.library.path)。
  - jsvc 装入 `%{_libexecdir}/tomcat8/jsvc`。
- 新增 `.github/workflows/build-rpm.yml`：matrix 构建 x86_64 / aarch64（用 QEMU 模拟 arm64 跑 rockylinux:8 容器），
  `dnf builddep` 自动装 BuildRequires，`rpmbuild -bb` 出包；tag 推送时 release job 去重 noarch 并发布。
- 前置：需把 `apache-tomcat-8.0.26.tar.gz` 提交进仓库（~8.7MB），否则 checkout 取不到 Source0。
